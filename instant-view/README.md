# Instant View для Telegram

Карточка ссылки (заголовок, описание, картинка) работает сразу — через Open Graph теги.
Кнопка **⚡ Instant View** требует отдельного шаблона.

## Как настроить (один раз)

1. Открой https://instantview.telegram.org и залогинься через Telegram.
2. Введи адрес любой статьи, например `https://startpointdev.com/blog/how-this-site-works/`.
3. В редакторе слева вставь содержимое [`template.txt`](./template.txt).
   Справа сразу видно, как статья будет выглядеть в IV. Проверь пару статей с картинками и кодом.
4. Нажми **Track Changes** и затем кнопку с идентификатором шаблона — получишь ссылку вида
   `https://t.me/iv?url=...&rhash=XXXXXXXXXXXXXX`.
5. Скопируй значение `rhash` в `src/data/site.ts` → `instantViewRhash`.

После этого кнопка «Скопировать ссылку для Telegram» на странице статьи будет выдавать ссылку
`t.me/iv?url=…&rhash=…`. Такая ссылка открывается в Instant View у всех, даже если Telegram
ещё не одобрил шаблон официально.

Можно также отправить шаблон на модерацию (Submit) — если его примут, IV заработает и для
обычных ссылок `startpointdev.com/blog/...`, но на скорое одобрение лучше не рассчитывать.

## Если поменяется вёрстка статьи

Шаблон опирается на: `article h1`, `.author`, `time[datetime]`, `.article-body`
(см. `src/pages/blog/[slug].astro`). Если переименуешь классы — обнови шаблон.
